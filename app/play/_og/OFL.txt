Fonts for the /play share card (app/play/opengraph-image.tsx)
==============================================================

These two files are SUBSETS of fonts released under the SIL Open Font
License 1.1, cut on 2026-10-11 with the Google Fonts CSS API's `text=`
parameter so they hold only the glyphs the card draws. They are read at build
time to render a PNG; the image is not covered by the licence (see the
PREAMBLE and condition 5 below), the font files are.

tan-dash-pixel.ttf
  A subset of Press Start 2P, version 3.000.
  Glyphs: space 0-9 : A B D E G H M N R S T
  "Press Start 2P" is a Reserved Font Name, and a subset is a Modified
  Version, which condition 3 forbids from using it as its primary font name.
  So this file's naming table (name IDs 1, 3, 4 and 6) was rewritten to
  "Tan Dash Pixel" / TanDashPixel-Regular; its copyright and licence
  entries are untouched.

dotgothic16-subset.ttf
  A subset of DotGothic16, version 1.100.
  Glyphs: space - . / 2 5 8 A J L N P T a b c e f g h i j k l m n o p r t u y
          · 人 入 大 山 川 日
  No Reserved Font Name, so the subset keeps its name.

To draw a glyph the card does not use yet, cut a new subset with the full
set of characters it needs (`https://fonts.googleapis.com/css2?family=<Family>
&text=<url-encoded characters>`, fetched with a non-browser user agent so the
response names a TTF, not a WOFF2, which Satori cannot read). For Press
Start 2P, rewrite those name IDs again before committing it (fontTools'
`ttx` round-trip does it).
